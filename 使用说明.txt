pmcontrol v1.2.1 — PROMAX 频道表批量测试（Windows 64 位）
=====================================================

一、怎么运行
------------
1. 把整个 pmcontrol 文件夹解压到任意位置（桌面、D 盘都行）。
   本版是单文件程序（pmcontrol.exe），不再需要 _internal 之类的
   附加文件夹；但同目录必须有 CH 文件夹（放频道表），缺了启动时
   会弹框提示，不会静默退出。
2. 双击 pmcontrol.exe。首次打开约 2~3 秒（单文件版要先自解压到临时
   目录），之后就快了。
3. 首次运行会在同目录自动生成 config.json（存你的设置），删掉它
   程序会恢复默认设置，不会丢演示数据。

二、第一次启动被 Windows 拦？
-----------------------
弹出"Windows 已保护你的电脑"是正常的 —— 作者没有购买代码签名证书
（个人开发者，证书每年要几千块）。处理方法：
    点「更多信息」→「运行 anyway」。
只用这一次，以后双击直接开。杀毒软件同理，加信任即可。

三、上手演示（不需要仪器）
--------------------
程序自带 5 个演示预设（界面右侧下拉框），配套的演示频道表已放在
CH/TER 和 CH/SAT 里，选一个直接点「开始测试」就能看到完整流程。
演示模式没有真实仪器，锁定时请配合本地模拟器或忽略结果数值。

四、频道表管理（v1.1 起）
--------------------
顶栏「频道表管理」按钮进去，三块功能：

· 编辑：新建 / 重命名 / 复制 / 删除频道表；表内可以加频点、删频点、
  改频点（双击行即可编辑），也能上下移动和按频率排序。射频表放
  CH/TER，卫星表放 CH/SAT，两者分开管理。

· 备份：每次保存 / 删除 / 改名之前自动打包一份到 bak/ 目录，滚动
  保留最近 10 份；也可以手动点「立即备份」，或从历史备份里还原。

· 同步：接上仪器后，可以直接把设备上的频道表下载到本地，也可以把
  本地表上传回仪器。上传需要仪器固件支持，不支持时会明确报错，
  不会盲写。
  下载和上传都能一次选好几张表，选法跟 Windows 资源管理器一样：
  单击选中一张，Ctrl+单击加选（再点一次取消），Shift+单击选一段，
  Ctrl+A 全选。多张表遇到本地/设备已有同名的，会一次性问清楚：
  「是」全部覆盖、「否」跳过重名只处理新的、「取消」都不动。

注意：仪表里的模拟频道，程序里显示和编辑的永远是「图像载频」，
实际写进文件时会自动 +2.75MHz，这是仪器格式要求，不用手动换算。

五、版本号与「关于」
----------------
设置窗口最后一页「关于」里能看到：版本号、更新日期、GitHub 项目地址
（可点开浏览器）、运行环境，以及配置文件与频道表目录的位置。
遇到问题想反馈，「复制版本信息」会把这一页的内容复制到剪贴板，
直接粘贴给人看就行，省得来回问"你装的哪一版"。
升级方法：到 GitHub 的 Releases 页面下载新版 zip，解压覆盖程序文件即可，
config.json 和 CH 里的频道表都不受影响。

六、连真实仪器
------------
1. 仪器和电脑连同一网络（仪器 WiFi 或网线）。
2. 设置里填仪器 IP 和端口（默认 2222）。
3. 把自己的频道表 XML 放进 CH/TER（射频）和 CH/SAT（卫星），
   然后在设置里建预设组。频道表从仪器导出，含真实运营数据，
   请按内部保密要求保管，不要外传。

七、结果文件
----------
默认存到系统"下载"文件夹，文件名可用 {date8}/{date6} 占位符。
设置里可切换 xlsx / csv，勾选"同时生成 Promax 格式文件"后还会
额外生成一份仪器格式的 .XML，供只认仪器导出文件的软件读取。

八、常见问题
-----------
· 双击没反应，或弹框说找不到 CH：把 CH 文件夹放到 pmcontrol.exe 同一目录。
· 开机第一次打开慢几秒：单文件版要先自解压到临时目录，属正常现象。
· 杀毒软件报毒：PyInstaller 打包的 Python 程序常见误报，加信任即可。
· 界面乱码：系统区域设置改成中文，或安装中文字体。
· 换了电脑设置没了：设置存在程序目录的 config.json 里，
  把这个文件一起拷走即可。
· 点「设备上的表…」弹「仪器没有应答」：仪器接受了网络连接，但一个字节
  都不回。多半是 ① 仪器还挂着上一次的会话 —— 等 30~60 秒再试，或拔插
  一次网线；② 另一台电脑或某个软件（比如厂家的遥控软件）正连着这台仪器，
  它只允许一个连接 —— 先断开那边；③ 仪器的网络服务卡死 —— 断电重启一次
  仪器。这三种都不是命令参数的问题，改设置没用。
· 想在仪器旁边确认到底卡在哪一步：把 _probe_io.py 和程序放一起，运行
  python _probe_io.py --ip <仪器IP>，它会先做"连接体检"，不通就直接
  收工并说明原因；通了就把每条命令的原始字节都记下来，把生成的
  probe-<时间> 目录发回来即可。
